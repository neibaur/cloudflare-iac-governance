# Security Policy

## Supported versions

Only the current `main` branch receives security updates.

## Reporting a vulnerability

Report vulnerabilities through GitHub private vulnerability reporting in this repository's
**Security** tab. Include a concise description, affected paths, reproduction steps, and impact
when available. Do not open a public issue for an undisclosed vulnerability and do not include
credentials or sensitive infrastructure data in the report.

## Scope

Reports may cover this repository's code, Terraform configuration, automation, and GitHub Actions
workflows. Cloudflare products, services, and platform behavior are outside this repository's
scope and should be reported through Cloudflare's own security process.

Findings that require a credential already to have leaked, without identifying a repository flaw
that caused or worsened the disclosure, are out of scope. Also out of scope are social
engineering, denial-of-service testing, and tests against infrastructure or accounts without
authorization.
